# LunarGateway
LunarGateway é um plugin para servidores Minecraft que adiciona funcionalidades personalizáveis como um menu interativo, teleportes automáticos e a icônica bússola mágica. Com configuração simples e integração prática, ele transforma a experiência dos jogadores, trazendo organização e imersão ao servidor. Criado por Ethan com a ajuda de Luna. 🌙✨
